# ワールド生成方針

## 結論

Mainワールドは再作成しません。

今回追加したFarming for Blockheads、Puzzles Lib、Visual Workbench、Camera Mod、SecurityCraft、Project MMO、Artifacts、Aquaculture 2、Spice of Life: Carrot Editionを理由に、既存の生活ワールドを削除する必要はありません。

## エリア方針

- スポーン周辺・既存生成範囲: 生活、建築、公共施設の保護領域
- 未生成チャンク: 新構造物の探索領域
- Resourceサーバー: 鉱石、構造物、探索、月次リセット用途

## 注意

- Artifacts等の新規構造物は未生成チャンクで生成される
- Worldgen系MODが確定するまでChunkyの事前生成範囲を拡大しない
- Mainの既存チャンクを安易に削除しない
- 限定再生成時はClaim、Waystone、AE2、SecurityCraft、Corpse、公共道路を除外する
- Mainのチャンク操作前はS3バックアップを取得する
